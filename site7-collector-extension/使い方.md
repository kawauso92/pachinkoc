# Site7 Collector 使い方ガイド

サイトセブン（site777.jp）で表示中の台データ（出玉推移・大当り履歴・出玉詳細）を読み取り、
回転率や期待値を計算して CSV に出力する Chrome 拡張機能です。

> ご自身のサイトセブン有料セッションをそのまま使う方式です。各自のアカウントでご利用ください。

---

## 1. 動作環境

- パソコンの **Google Chrome**（最新版推奨）
- サイトセブンのアカウント（閲覧できる状態）

## 2. インストール手順

1. 配布された ZIP を**解凍**します（フォルダ `site7-collector-extension` ができます）。
2. Chrome で `chrome://extensions/` を開きます。
3. 右上の「**デベロッパー モード**」を **ON** にします。
4. 「**パッケージ化されていない拡張機能を読み込む**」を押します。
5. 解凍した **`site7-collector-extension` フォルダ**を選択します。
6. ツールバーに拡張アイコンが出れば完了です。

## 3. 基本の使い方（手動）

1. サイトセブンで対象の店舗・機種・台・日付のページを開きます。
   - 拡張が有効な間は、自動的に iPad として表示されます（PCだと弾かれるため）。
2. 拡張アイコンを開き、右下の検出表示で「店舗・機種・台番・営業日・画面」が正しいか確認します。
3. 「**現在のページを保存**」を押します。別画面（出玉推移／大当り履歴／出玉詳細）でも同じ台・同じ日を保存すると、1台のデータとしてまとまります。

## 4. 自動巡回（複数台をまとめて取得）

1. **出玉推移ページ（…/D2600.do）** を開きます（必ずここから開始）。
2. 拡張の「自動巡回」で、
   - **台番号(dn)**：空欄ならページ内の台番号セレクト/リンクから自動検出。手動指定する場合は `406-415,466-475` や `181,182,190-195`
   - **日付(dtdd)**：空欄なら表示中の日付のみ。`0` が当日、`1` が1日前、複数日は `0-3` や `0,1,2,3`
   - **取得画面**：出玉推移／大当り履歴／出玉詳細（既定で全部ON）
   - **機種**：出玉が取れない店では機種を選び、出玉内訳（超/中/小）を指定（後述）
3. まず「**ドライラン**」ONで「開始」→ 生成されるURLを確認。
4. 問題なければドライランOFFで「開始」。巡回中は対象タブを前面のままにしてください。
5. 混雑ページが出たら自動で待機（バックオフ）し、続きを再開します。「停止」で読込待ちや接続リトライも含めて中断します。

## 5. 回転率・期待値の計算について

- **回転率**：通常スタート・払出（大当り出玉）・差玉が揃えば自動計算されます。
- **期待時給・仕事量**：機種スペック（appa/appb）と交換率が解決できた台だけ計算されます。
  未対応の機種は計算されず、メモに理由（`machineSpecMissing` など）が出ます。
- **大当り履歴に出玉情報が無い店**：巡回前に「機種」を選び、出玉内訳（超/中/小のR）を指定すると、
  払出を推定して回転率を出します（**推定値・精度低め**。メモにその旨を表示）。実際に払出が取れた台は推定で上書きしません。
- **遊タイム行がある機種**：履歴の「遊タイム」行の右端にある括弧内の回転数（例: `(289回)`）を通常回転から引いて計算します。
- **自動解析差玉が±30000発を超える台**：グラフ表示範囲外または軸誤検出として扱い、差玉は採用しません。メモに「差玉計測不能」を出し、差玉・推定使用玉・回転率・期待時給・仕事量は空欄になります。
- **稼働0の台**：「未稼働」と表示します。

## 6. データの書き出し

- **今回データCSV**：popup を開いて以降に保存・更新した分だけ出力。
- **条件を指定してCSV出力**：日付・機種（解決後名）で絞って出力。
- **JSON（全量バックアップ）**：全データをそのまま保存。
- **デバッグCSV / デバッグ情報コピー**：取得がうまくいかない時の調査用。
- 出力ファイルは UTF-8（BOM付き）。Excel でそのまま開けます。

## 7. 注意事項

- 取得データはお使いの Chrome 内（ローカル）にのみ保存されます。
- 「全削除」を押すと保存データは消えます。必要なら先に CSV / JSON を出力してください。
- サイトに負荷をかけないよう、巡回の遅延（既定 2000〜5000ms）はむやみに短くしないでください。

## 8. うまく取れない時

- 機種名や台番が違う → 拡張の「手動補正」で修正、または巡回前に「機種」を選択。`ホールTOP` などのページ名は機種名として出力しないようにしています。
- 値が取れない → popup の「**デバッグ情報をコピー**」して内容を確認してください。
